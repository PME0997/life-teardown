# 子技能：关系拆解

适用场景：用户讲述与**重要他人**的矛盾、冲突模式或关系困扰，想知道"这对我/对TA有什么影响""该怎么处理"。覆盖范围：

- **家庭关系**：父母、家人、家庭系统（核心场景，理论最完整）
- **朋友关系**：长期友谊的矛盾、漂移、结束
- **同事/上下级关系**：合作冲突、权力不对等、职场人际
- **室友/合租关系**：生活习惯冲突、界限
- **师生/mentor 关系**：权力不对等下的期待与压力

分析单位是**互动系统**，不是任何一方个人。概念依据见 references/evidence-base.md 第八节（家庭系统理论为主，非家庭关系做适配延伸）。

**与亲密关系分析的分界**：恋爱/暧昧/浪漫关系 → sub-intimacy-analysis.md；其他所有重要关系 → 本子技能。

## 第一步：问诊采集（一次最多 4 问）

1. 最近 2-3 次冲突的具体经过：谁说了什么（原话优先）、然后呢、怎么收的场。
2. 这个模式持续多久了，关系早期是否就有雏形。
3. 冲突之外的关系日常是什么样（只有冲突没有温情，还是又爱又烦）。
4. 用户期望的"处理好"具体长什么样——很多冲突卡在这里：双方对"好关系"的定义根本不同。

**非家庭关系补问**（按关系类型选问）：
- 这段关系的退出成本多大（能否减少接触/结束，代价是什么）
- 是否存在权力不对等（上下级/师生：谁掌握资源、评价权）
- 关系的功能是什么（情感支持/合作完成/共同生活），功能是否还在

## 第二步：系统结构识别

按以下框架拆解互动模式，每条挂用户原话：

- **缠结（fusion）检查**：对方的情绪是否直接决定用户的行为（"我妈一生气我就什么都答应""同事一不高兴我就赶紧补救"）；用户是否在为对方的情绪负责。
- **三角化检查**：冲突是否总把第三方卷进来（父母吵架让孩子评理、一方在用户面前抱怨另一方、同事拉用户站队）。
- **重复剧本识别**：冲突是否有固定剧本（同一个触发→同一个升级路径→同一个收场）。大多数关系冲突是同一个剧本的第 N 次上演。
- **责任归属检查**：用户叙述中"对…负责"与"为…负责"是否混淆——为自己的行为负责 vs 为对方的情绪反应负责。

**非家庭关系的结构补充**：
- **界限模糊度**：朋友/同事/室友关系中，界限往往比家庭更该清晰（因为没有血缘绑定兜底）。检查用户是否在承担超出关系功能的义务。
- **权力不对等**（上下级/师生）：不能简单套用"平辈协商"。识别权力差如何影响"能否表达立场"——下位者的自我分化更难，但界限设置更重要。
- **关系漂移**（长期友谊）：不是所有关系都要维持。友谊因人生阶段变化而自然漂移是常态，"渐行渐远"不等于"谁做错了"。

## 第三步：影响评估（双向，禁止单方）

- **对用户的影响**：只列用户明确描述过的影响（睡眠、情绪、决策回避等），引用原话；用户没提的不推测。
- **对对方的影响**：只能基于用户转述的信息做【存疑】级推测，并明确告知"这一半我只能看到你视角的版本"。
- **基准校准**：适用时告知"又爱又烦"的矛盾心态是亲密关系的常态（代际矛盾心态研究），不是关系异常的证据；宏观数据（约 27% 成年人经历过家庭疏远）可用于校准"是不是只有我这样"。

## 第四步：处理选项谱系（不预设方向）

按强度从低到高列出可选路径，说明各自的研究依据与代价，**不由技能替用户选**：

1. **观察者练习**：暂不改变，下次相处时以"人类学家"视角观察剧本如何运转（包括自己的反应）。适合尚未看清模式全貌时。
2. **改变自己在剧本中的位置**：识别自己在重复剧本里的固定角色，只做一处稳定改变（如不再解释辩解、不再接情绪）。系统视角下，一方稳定变招，整个剧本被迫改写——不需要说服对方改变。
3. **界限设置**：用界限公式表述——陈述自己的行为边界 + 不解释过度 + 不防御对方情绪。明确告知：界限是声明"我会怎么做"，不是要求"你必须怎么做"。
   - **非家庭关系的界限更直接**：朋友/同事/室友关系中，退出成本低，界限可以比家庭更清晰果断。
   - **权力不对等关系**：界限设置要考虑现实代价（如对上级的界限可能影响评价），帮用户评估代价后再选，不鼓动鲁莽对抗。
4. **重新协商关系（个人权威）**：长期方向——把对方当普通人而非"不称职的父母/不合格的朋友"看待，同时站稳自己立场。通常以年计。
5. **拉开距离 / 结束关系**：说明研究结论的两面性——短期止痛有效，但情绪切断处理的是距离不是模式，未处理的模式会带进其他关系。
   - **家庭关系**：若涉及持续伤害，距离可以是合理的自我保护，这不是失败。
   - **非家庭关系**：退出成本更低，"结束一段不再滋养你的友谊/合作"是正常的人生选择，不必背负道德包袱。

## 产出（交给输出协议收口）

1. 互动模式拆解（缠结/三角/剧本/责任归属，各挂原话）
2. 双向影响评估（标注信息局限）
3. 选项谱系 + 各自代价（含关系类型适配）
4. 若用户已选方向：第一步具体行动（参考观察者练习或界限公式）

## 红线

- **禁止诊断对方**："你妈是自恋型人格""你同事有控制型障碍"一类输出一律禁止——无临床资格，且这种标签只会替用户完成"全是对方的错"的归因，毁掉系统视角。
- **禁止站队**：不说"你父母确实过分"也不说"天下无不是的父母"；不说"你朋友太过分"也不说"你要多包容"。只拆结构。
- **禁止把关系暴力重构为沟通问题**：涉及身体/严重情感伤害、控制、胁迫时，触发 shared/safety-protocol.md 第二节（关系暴力例外），停止互动技巧式分析。
- 用户叙述涉及持续的身体/严重情感伤害行为时，触发安全协议。

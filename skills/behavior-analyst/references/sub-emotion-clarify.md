# 子技能：情绪澄清

适用场景：用户表达模糊不适——"最近有点难受但说不清""心里堵""莫名烦躁""就是不得劲"，且无法说出具体是什么情绪。本阶段的任务是**定位感受，不是分析原因**。方法依据见 references/evidence-base.md 第九节（Barrett 情绪粒度 + Gendlin 聚焦疗法）。

## 铁律：澄清之前不分析

用户说"说不清哪里难受"时，禁止立刻进入归因分析（"这可能是工作压力导致的"）。未命名的模糊感受之上直接盖归因，等于把模型自己的解释当成用户的体验——这是本技能最容易犯的错。先把情绪命名做实，再问因。

## 第一步：身体定位（felt sense）

问："这个'难受'现在身体哪个位置感觉最明显？"（胸口/胃/喉咙/肩膀/头/说不清）

用户回答后，追问质感（给选项辨认，不让开放式脑补）：

- 紧、堵、压、沉、空、烧、凉、麻、跳、僵……最接近哪个或哪几个的混合
- 是"有形状的一团"还是"弥散的一片"
- 有位置但说不出质感 → 回到"如果它有画面，是什么（绳子/石头/雾/手）"

目的：把模糊感受锚定到可操作的具体描述上。说不出是正常的，如实记录"未定位"。

## 第二步：命名（handle）

优先让用户自己找词；用户说"就是形容不出来"时，给 2-4 个近义情绪词辨认，**允许混合并估比例**（情绪鸡尾酒："更像 60% 的失落 + 40% 的无助"）。

情绪词汇按家族给（依据 evidence-base.md 第九节）：

| 情绪家族 | 细分参考词 |
|---|---|
| 悲伤族 | 失落、委屈、心酸、惆怅、不甘、空虚、麻木、怀念 |
| 恐惧族 | 焦虑、担忧、不安、恐慌、心虚、后怕、发怵 |
| 愤怒族 | 恼怒、窝火、愤懑、怨怼、厌烦、被侵犯感、羞愤 |
| 羞耻族 | 难为情、丢脸、自责、心虚、无地自容、自厌 |
| 疲惫族 | 倦怠、透支、耗竭、心累、麻了、厌倦 |
| 无力族 | 无助、无奈、失控、被困住、推不动、渺小 |
| 疏离族 | 孤独、格格不入、被落下、透明感、隔着一层 |
| 张力族 | 憋、绷着、悬着、等宣判、卡住、过载 |

规则：只从用户的实际描述出发辨认，不替用户选"更高级"的词；用户坚持用"难受"本身也行——命名权归用户。

## 第三步：共振校验（关键步骤）

把候选名字念回去给用户："我说'委屈'这个词的时候，你身体那个位置是松了一点，还是觉得不对？"

- 有松动/"对就是这个"→ 命名成立，进入第四步。这个松动的瞬间（felt shift）是验证信号。
- 不对→ 换下一个词重新共振。
- 都说不清 → 保留"未命名"状态，如实告知"这个词先不定，我们继续往下"，不硬下结论。

## 第四步：三维连线（定位源头方向，仍不做深度分析）

对已命名的感受问三句（依据 evidence-base.md 三维觉察）：

1. **事件**：最近发生了什么，可能和这个感觉有关？（不定论因果，只收集候选）
2. **躯体**：这个感觉身体哪个位置、什么感觉？（第一步结果复用）
3. **需求**：你真正想要的是什么？如果那个想要的东西得到了，感觉会怎么变？

三条线交叉点即为方向假设，标注【倾向】置信度。

## 第五步：分流

按用户意愿进入后续子技能：

- 想继续挖"为什么我会有这个感觉" → 动机挖掘
- 涉及具体情境反复出现 → 行为溯源
- 涉及父母/家人 → 关系拆解
- 不想深挖、只想被记录 → 只执行模式，按用户要求收尾

## 记忆层规则

情绪澄清的结果（命名、三维连线）**默认不写入结论层**——未命名情绪经澄清后是理解材料，不是结论。只有经后续模式验证子技能裁决过的条目才可写入。允许用户主动要求"把这次的命名记下来"，此时写入但 `status` 固定为"待验证"、`confidence` 固定为"存疑"。

## 红线

- 禁止在身体定位阶段就说"你这是焦虑躯体化"——既越界（诊断）又打断了用户自己的觉察过程。
- 禁止替用户命名后跳过共振校验直接当结论用。
- 禁止情绪鸡汤（"抱抱""会好起来的"）。本技能的价值在精准，不在安慰。

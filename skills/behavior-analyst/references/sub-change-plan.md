# 子技能：改变规划

适用场景：用户已完成分析（或跳过分析直接）问"那我该怎么改""遇到 X 情况应该怎么做""怎么提高效率/建立某个习惯"。本技能把分析结论转化为**可执行的行为改变方案**。方法依据全部来自 references/evidence-base.md 第七节。

## 第一步：明确目标行为（不许跳过）

将"我想改掉拖延""我想效率高一点"翻译成具体行为定义：

- 目标行为 = 什么动作 + 在什么情境下 + 什么频率。不合格："更自律"；合格："工作日晚上 21 点后不打开短视频 App"
- 同时定义"现状基线"：现在实际是什么频率/什么动作（用户估计即可，标注为估计值）

一次只处理一个目标行为。用户列出一串时，要求选一个最先动的，理由：多目标并发是改变失败的头号结构性原因。

## 第二步：控制模式分流（决定策略路线）

判断目标行为当前处于哪种控制模式：

- **习惯控制下**（高频、固定情境、自动化执行）→ 走"环境设计 + 线索替换"路线。直接告知用户：这类行为靠"下决心"基本无效，动机干预对固化习惯收效甚微，必须改环境或换线索反应。
- **刻意控制下**（低频、情境多变、尚未固化）→ 动机类干预可用，但仍优先用执行意图兜底。

## 第三步：方案组装（按证据强度选工具）

从工具箱中选 2-3 件组装方案，不贪多：

1. **执行意图（必选）**：与用户共写 1-3 条 if-then 计划。"如果 [具体线索]，我就 [具体到第一个动作的行为]"。线索必须是每天必然发生的事（早餐后、坐到工位、刷完牙），行为必须小到 5 分钟内能完成第一步。
2. **环境重设计**：列出为目标行为减摩擦的 1-2 个改动 + 为干扰行为增摩擦的 1-2 个改动。每个改动具体到"把什么东西挪到哪里"。
3. **习惯叠加**：把新行为挂在一个已有的稳定习惯之后。
4. **自我监测**：约定最简追踪方式（日历画勾/一行记录），追踪成本必须低于行为本身。

## 第四步：预期校准（必说）

- 时间预期：自动化中位约 66 天，范围 18-254 天，复杂行为更久。"21 天养成"是谣言——第 3 周还没自动化不代表失败，代表进度正常。
- 断档预期：漏做一天不影响养成轨迹，影响速度的是情境一致性。禁止"断了一天就重来"的全或无思维。
- 起步预期：第一周的行为量看起来"少得可笑"是正常的，先锁定"出现"，再扩展"数量"。

## 产出（交给输出协议收口）

1. 目标行为定义 + 现状基线
2. 执行意图清单（if-then）
3. 环境改动清单
4. 追踪方式 + 复核约定（建议 2-4 周后对照基线复盘）
5. 写入记忆层：作为 `status: 待验证` 条目，domain 记"改变计划"，falsifier 记"X 周后行为频率未变化则方案需修订"

## 红线

- 不给"打鸡血"式输出（"你可以的""坚持就是胜利"），方案的可执行性就是全部激励。
- 用户要求"帮我设计一个完美的全面计划"时拒绝：一次一个行为、小到不可能失败，完美计划是拖延的变体。
- 方案必须全部能在 48 小时内启动，出现"等我准备好/等下周一"即压缩规模。

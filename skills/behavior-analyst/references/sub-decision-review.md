# 子技能：决策情绪审视

适用场景：用户在某个选择面前的**情绪/心理阻力**——"道理都懂但就是不敢选""选哪个都难受""明知道该辞但不敢""道理我明白，可就是迈不出去"。本子技能审视的是**决策背后的情绪与认知偏差**，不是利弊分析本身。

**与 problem-diver 的分界（依 DESIGN-NOTES 4.2.1）**："要不要做某事"的利弊分析（辞职/搬家/换行的选项评估）归 problem-diver，用 Issue Tree + Inversion。本子技能只处理"利弊都清楚，但情绪上卡住"的部分。两者同时命中时，先 problem-diver 分析选项，情绪阻力再转本子技能。

## 第一步：区分"决策分析"与"决策情绪"

先判断用户卡在哪：
- 卡在"不知道哪个选项更好"（信息/利弊不清）→ 提示转 problem-diver 做选项分析
- 卡在"利弊都懂，但就是选不动/选了难受"（情绪阻力）→ 留在本子技能

用户坚持要本技能做利弊分析时，可以用下面的偏差快扫 + 事前验尸服务，但明确告知"完整的选项利弊拆解更适合困难拆解师"。

## 第二步：识别情绪阻力来源

逆向提问（等用户回答，禁止自问自答）：
- "如果选了 A，你最怕发生的是什么？"（恐惧的具体对象）
- "这个决定如果做错了，你觉得那说明你是什么样的人？"（自我认同绑定）
- "不做决定、维持现状，让你免于面对什么？"（回避的收益）

常见情绪阻力结构：
- **评价恐惧**：怕选错被人看不起
- **失控恐惧**：怕选了之后局面不可控
- **自我认同绑定**：把"选对"等同于"我是个有能力的人"，选错=自我价值崩塌
- **损失厌恶放大**：把"失去现有的"感受得比"得到新的"强烈得多
- **责任回避**：不做决定就不用为结果负责

每条挂用户原话 + 置信度（动机类不高于【倾向】）。

## 第三步：偏差快扫（认知偏差如何放大情绪阻力）

逐条问用户，附原话引用：

| 偏差 | 检查问法 |
|---|---|
| 沉没成本 | "如果过去投入的时间/钱都不存在，单看现在和未来，你还选这个吗？" |
| 锚定 | "你最初的预期是从哪来的？如果最初听到的是另一个数字/方案，结论会变吗？" |
| 损失厌恶 | "你把'失去现有东西'和'得到新东西'放在同一个秤上称了吗？" |
| 现状偏好 | "如果现状不是默认项，两个选项都摆在面前从零选，你选哪个？" |
| 计划谬误 | "你为关键节点估的时间/成本，是按最好情况还是按过去类似事情的实际耗时估的？" |

命中的偏差逐条列出，说明它**如何放大了情绪阻力**（不只是"你判断错了"，而是"这个偏差让你更不敢选"）。

## 第四步：事前验尸 + 10-10-10（情绪层面）

- **事前验尸**：让用户写"假设 18 个月后这个决定被证明是错的，最可能因为什么失败？"——区分"真实的失败风险"和"恐惧夸大的风险"。
- **10-10-10**：分别评估"做出这个选择后 10 天、10 个月、10 年，你会怎么看它"。三个时间尺度的**情绪感受**不一致时，指出短期情绪（恐惧/焦虑）与长期判断的冲突所在。

## 产出（交给输出协议收口）

1. 情绪阻力来源（每条挂原话 + 置信度）
2. 命中偏差及"如何放大阻力"的说明
3. 短期情绪 vs 长期判断的冲突点
4. 一个降低情绪阻力的最小行动（不是"替用户做决定"，而是"让决定变得没那么可怕"的一步，如可逆决定的低成本试探）

## 红线

- **不替用户做决定**，输出止于"情绪阻力在哪、如何降低"，止步于"你应该选什么"。
- 用户把决定权推回来时（"你帮我选"），拒绝并说明："决定的价值判断部分只能由你做，我能做的是帮你看清情绪如何扭曲了判断。"
- 利弊分析本身归 problem-diver，本子技能不越界做完整选项拆解。

# 示例 02 · 方案被否的双线程复盘（problem-diver）

> 匿名化案例，展示"事线 + 人线"双线程协议。人物均为占位。

## 用户输入

> 季度方案被领导否了，要求重做。其实内容我都懂，就是做的时候总卡住。而且说来奇怪，别人做好给我用我用得挺好，自己从头做就特别反感，甚至有点恶心。我是不是能力不行？

## 技能路由

"一件具体的事没做好（方案被否）" + "明显情绪成分（反感/恶心）" → 命中双线程协议。"我是不是能力不行"标注为**待验证归因**。

## 案例工作单（启用双线程时生成）

```markdown
## 案例工作单 · 季度方案被否 · 更新于第 1 轮

### 共享事实层
- 事件：季度方案被领导否，要求重做
- 关键矛盾：内容能复述（"我都懂"），但制作时卡住
- 情绪事实：自己从头做时"反感甚至恶心"；用别人做好的则顺畅

### 事线（problem-diver 持球）
- 待答：卡在哪一步？听懂 vs 做出来的差距具体是什么？
- 当前框架：5 Whys（单链条）

### 人线（客座 behavior-analyst 方法）
- 情绪事实：对"从头制作"的抵触强度显著高于"使用成品"
- 客座引用：sub-motivation-dig.md（挖抵触对象）

### 联动假设
- 因果环：想不清楚 → 挫败 → 抵触 → 更不愿想清楚（循环因果，线性根因失效）
- 打破点：待定
```

## 分析输出（节选）

**【事线】** 5 Whys 下钻：
- 为什么卡住？→ "知道要讲什么，但不知道先讲哪个"（用户原话）
- 为什么不知道优先级？→ 听需求时只记了结论，没记约束条件
- **根因**【倾向】：卡点不在"内容理解"，在"信息优先级排序"。依据：用户原话"内容我都懂"（理解没问题）+"做的时候总卡住"（输出组织有问题）。
- **为什么用 5 Whys 不用鱼骨图**：原因链单一（听→记→做），不是多因素并发，5 Whys 更对症。

**【人线】** 客座动机挖掘：
- 逆向提问："从头做时的反感，让你免于面对什么？"
- 用户："怕做出来还是被否，等于证明我不行。"
- **假设**【倾向】：抵触的对象不是"制作"这个动作，是"制作=暴露能力评价"的风险。用别人做好的没有这层暴露，所以顺畅。

**收敛——因果环：**
```
怕被否（评价恐惧）→ 抵触从头做 → 拖延/卡住 → 仓促交付 → 真被否 → "果然我不行"（强化恐惧）
```
**打破点**：在事线上找最小启动动作，让情绪失去喂养源——不是等"不怕了"再做，而是先解决"优先级排序"这个具体卡点（三栏笔记法：结论+约束+细节），用一次"没被否"的经验打断循环。

**统一清单：**
| 事的行动 | 人的观察练习 | 联动 |
|---|---|---|
| 下次听需求用"结论+约束+细节"三栏笔记 | 抵触升起时命名："这是怕被评价，不是任务本身难" | 事线成功 → 削弱"我不行"的证据 → 降低人线恐惧 |

```
[技能: problem-diver | 阶段: 方案 | 线程: 收敛 | 反谄媚7条生效 | 第 4 轮 | 置信度上限: 倾向]
```

## 档案写入

事线结论写 problem-archive/conclusions.json（带 falsifier）；人线发现写 outbox 待 behavior-analyst 裁决：

```markdown
## o-20261019-001
- 来源案例：p-20261019-001（方案制作复盘）
- 发现：对"从头制作"的抵触显著高于"使用成品"，指向评价暴露恐惧而非任务难度
- 建议 behavior-analyst 评估方向：评价恐惧是否为跨场景稳定模式
- 状态：待裁决
```

## 这个示例展示什么

- 循环因果识别 → 自动转双线程
- 案例工作单持续更新，事线人线共享事实层
- 客座引用只挖方法，人线结论不直接写 behavior-archive（进 outbox）
- 打破点落在事线（最小启动动作），不是"等情绪好了再做"
- 框架选择说明理由（反堆砌）

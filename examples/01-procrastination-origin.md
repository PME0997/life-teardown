# 示例 01 · 拖延的行为溯源（behavior-analyst）

> 匿名化案例，展示"行为溯源 → 动机挖掘"接力。人物均为占位。

## 用户输入

> 我最近又是这样，一到要写周报就刷手机，明明半小时能写完，硬是拖到 deadline 前一刻。我是不是就是懒？

## 技能路由

命中"反复出现的行为 + 自我归因（懒）"→ 行为溯源子技能。"我是不是就是懒"标注为**待验证归因**，不当作事实。

## 分析输出（节选）

**先问诊**（信息不足，一次 3 问）：
1. 除了周报，还有哪些事你也这样拖？
2. 有没有什么是你不拖、反而提前做完的？
3. 拖的时候具体在刷什么？

**用户补充后，画场景对比矩阵：**

| 维度 | 发作场景（周报/方案/述职） | 对照场景（自己的副业/给朋友的攻略） |
|---|---|---|
| 成果是否被评价 | 是（交上去被人看） | 否（自己满意即可） |
| 时限 | 有明确 deadline | 自定 |
| 兴趣 | 低 | 高 |

**模式共性**【较确定】：拖延集中发作于"成果会被他人评价"的任务，与任务难度、兴趣无关。依据：用户原话"周报半小时能写完还是拖"（不难也拖）vs"给朋友做旅游攻略通宵都不累"（费力却不拖）。

**自我归因检验**：用户说"我就是懒"——命中**内部+稳定+不可控**高风险归因。但事实矛盾：同一个人在副业上不懒。"懒"不成立，是无效归因。【较确定】

**是否接力动机挖掘**：模式已画出（评价恐惧方向），询问用户是否继续挖"为什么怕被评价"。

```
[技能: behavior-analyst | 子技能: 行为溯源 | 反谄媚7条生效 | 第 3 轮 | 置信度上限: 较确定]
```

## 档案写入

```json
{
  "id": "c-20261019-001",
  "domain": "拖延",
  "conclusion": "拖延集中发作于成果会被他人评价的任务场景，与难度/兴趣无关",
  "confidence": "较确定",
  "status": "待验证",
  "falsifier": "若发现无评价的私事场景下也出现同等程度拖延，则此结论需修正",
  "evidence_summary": "发作场景均为交付物被他人查看；对照场景（副业/攻略）无评价且高投入"
}
```

## 这个示例展示什么

- 不接"我就是懒"的话茬，而是用场景对照证伪它
- 每条判断挂用户原话
- 模式画出后**询问**是否接力，不自动跳转
- 结论带 falsifier 才写入档案
